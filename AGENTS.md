# Bank It repository instructions

This repository is the editable source and deployment source for the `bank-it` Cloudflare Pages project. Production is https://bank-it.leotoby.com/ and builds from `main` with `npm run build` into `dist/`. Assets must work from `/`.

Do not use the retired `build:leotoby` or `copy:leotoby` workflow and do not copy playable files into the LeoToby homepage repository. For hosting details and the homepage link, see [LeoToby's hosting guide](https://github.com/MrHubble/leotoby/blob/main/docs/hosting.md).
